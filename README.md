## 🌠 About PyroNova AI

**PyroNova AI** is a modern, space-inspired web application designed to explore the possibilities of combining **Artificial Intelligence, space science, and NASA-related data**.

The project provides an immersive and futuristic experience where users can interact with space-related information through a visually engaging interface inspired by mission-control systems and cosmic exploration.

> **Mission:** Transform complex space information into an accessible, intelligent, and engaging digital experience.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/PyroNova-AI.git
```

### 2️⃣ Navigate to the Project

```bash
cd PyroNova-AI
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

Open the local URL shown in your terminal.

---

## 📦 Production Build

To create an optimized production build:

```bash
npm run build
```

Vite will generate the production files inside the:

```text
dist/
```

folder.
